# Controle de Estoque (Mobile)

Aplicativo mobile desenvolvido em **React Native** com **Expo** para controle e gerenciamento de produtos, categorias, fornecedores e movimentações de estoque.

## 📱 Recursos

- Cadastro e listagem de produtos com controle de quantidade mínima e máxima.
- Gestão de categorias e fornecedores.
- Registro de entradas e saídas de itens no estoque.
- Histórico de movimentações e visualização de alertas de estoque baixo.

## 🛠 Tecnologias

- **Framework**: React Native (Expo)
- **Linguagem**: JavaScript / Node.js
- **Navegação**: React Navigation
- **Armazenamento**: Local / Estrutura JSON

## 🚀 Como Executar

```bash
# Instalar dependências
npm install

# Iniciar o servidor Expo
npx expo start
```
